# Power BI ページ設計（4ページ）― 介護・高齢者ダッシュボード

共通: 全ページ右下に出典テキスト（厚生労働省「介護保険事業状況報告」令和6年度年報／総務省「人口推計」）と定義注記へのリンクを常設。
スライサーは都道府県（DimPref）を全ページ同期。

## ページ1 KPI概要
- カード×6: 第1号被保険者数 / 認定者数 / 認定率_公式_pct / 給付費_億円 / 被保険者1人あたり給付費_円 / 高齢化率_pct
- 棒グラフ: 介護度別 認定者数（FactPref の介護度7列をアンピボットして表示）
- 折れ線: 認定者数の推移（FactTrend、2021年度〜）
- 注記: 「認定率は公式値（第1号ベース）。給付費は介護給付・予防給付の範囲（高額介護等を含まない）」

## ページ2 都道府県・保険者
- テーブル: 47都道府県（被保険者数、認定者数、認定率_公式、給付費、1人あたり給付費、高齢化率）。認定率で条件付き書式
- 棒グラフ: 認定率_公式 TOP10 / 給付費 TOP10
- ドリルダウン: 都道府県選択 → 同ページ下段の保険者テーブル（FactInsurer）が連動
- 保険者テーブル初期表示は「被保険者数1,000人以上」にフィルター（小規模保険者の比率ブレ対策。フィルター条件はページ上に明記）

## ページ3 需給・給付の内訳
- 積み上げ棒: サービス3区分の受給者数（月平均換算メジャーを使用、ラベルに「延べ・重複利用あり」）
- 棒グラフ: 介護度別 認定者構成比（認定者に占める要介護3以上_pct 等）
- テーブル: 1人あたり給付費 上位・下位5都道府県
- 注記: 「1人あたり給付費の地域差は認定率・介護度構成・供給体制の差の反映であり、単独では効率性の指標にならない」

## ページ4 推移
- 折れ線: 第1号被保険者数 10年（65-74歳／75歳以上の内訳つき、FactTrend）
- 棒+折れ線: 認定者数と給付費（2021年度〜 exact 値）
- 注記: 「被保険者数の10年系列は概要第1表（千人単位・四捨五入）。認定者数・給付費の exact 値は2021年度分から全国計Excelで抽出。それ以前は未取得のため表示しない」

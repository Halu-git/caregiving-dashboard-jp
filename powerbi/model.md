# Power BI モデル設計 ― 介護・高齢者ダッシュボード（保険者別に見る介護需給）

## テーブル構成（data/processed/ の tidy CSV をそのまま取り込む）

| テーブル | 粒度 | 主な列 |
|---|---|---|
| FactPref | 都道府県（47行）× 令和6年度 | 第1号被保険者数、認定者数（介護度別7列＋合計）、認定率（公式）、給付費、1人あたり給付費、高齢化率 |
| FactInsurer | 保険者（1,573行）× 令和6年度 | 都道府県、保険者、第1号被保険者数、認定者数（介護度別＋合計）、認定者比率（参考）、給付費、1人あたり給付費、サービス別受給者数（累計） |
| FactRecipientsPref | 都道府県（47行） | サービス3区分の受給者数（当年度累計・延人月／1ヶ月平均） |
| FactTrend | 年度（2015–2024） | 第1号被保険者数（千人）、認定者数、給付費（2021年度〜 exact） |
| DimPref | 都道府県マスタ | 都道府県名、地域ブロック（任意付与） |

## リレーション
- DimPref[都道府県] → FactPref / FactInsurer / FactRecipientsPref（1対多、単方向）
- FactTrend は独立（全国推移専用。他テーブルと混在させない）

## 設計上の注意（定義の混在防止）
- **認定率（公式）**は FactPref の列（概要第3表の第1号ベース）をそのまま使う。FactInsurer の「認定者比率（参考）」は分子に第2号認定者を含む別定義で、**公式認定率と同一ビジュアルに混在させない**。measures.dax 側でも別メジャーとして分離する。
- 給付費は「介護給付・予防給付」の範囲。高額介護サービス費等を含む公表総額（12兆952億円）とは別物として、レポート内に範囲注記を常設する。
- 受給者数は延べ人月（重複利用あり）。月平均は ÷12 の計算列で持ち、ラベルに「1ヶ月平均（換算）」と明記する。
- 人口推計は2024年10月1日現在、介護保険は2025年3月末現在で**時点が異なる**。高齢化率は文脈指標としてのみ使う。

## 更新設計
- 年報の確定値公表（例年、翌年度後半）に合わせて CSV を差し替える年次更新型。
- 年度列を持たせた FactTrend のみ追記式。他テーブルは最新年度スナップショットとして置換する（複数年度の保険者比較が必要になったら FactInsurer に年度列を追加して縦持ち化する）。

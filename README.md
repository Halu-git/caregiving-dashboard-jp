# 介護・高齢者ダッシュボード（保険者別に見る介護需給）

介護保険の「需給」を、公式統計だけで全国・都道府県・保険者（市区町村）別に追うダッシュボードのサンプルです。Excel完成品、Power BI設計パック、整形済みCSVを含みます。

## 主な数値（令和6年度）

- 第1号被保険者数： 35,839,278人（2025年3月31日現在）
- 要介護（要支援）認定者数： 7,207,487人 ／ 認定率（公式・第1号ベース）19.7%
- 給付費（介護給付・予防給付）： 10兆6,187億円 ／ 被保険者1人あたり 296,287円/年
- 認定率（公式）は大阪府 24.3% が最高、宮崎県 16.3% が最低
- サービス受給者数（1ヶ月平均）: 居宅 4,319,340人 / 地域密着型 922,765人 / 施設 962,557人（延べ・重複利用あり）
- 高齢化率（人口推計 2024年10月1日現在）: 全国 29.3%

## 構成

- `excel/caregiving_dashboard.xlsx` ― Excel完成品（11シート、ネイティブグラフ8点）
- `powerbi/` ― Power BI設計パック（model.md / measures.dax / pages.md）
- `data/processed/` ― tidy形式CSV 4ファイル（出典列つき）。保険者別は1,573件
- `scripts/` ― 取得記録（download_sources.py）と整形（build_tidy.py）、Excel生成（build_excel.py）
- `design.md` ― 設計メモ（目的・検証結果・定義の注意・未取得/不採用データ）
- 生データ（約15MB）は容量の都合で同梱していません。`scripts/download_sources.py` の記録から公式ページで再取得できます

## データソースと採用理由

| データ | 採用理由 |
|---|---|
| 厚生労働省「介護保険事業状況報告」令和6年度年報（政府統計コード 00450351） | 認定者数・受給者数・給付費を都道府県別 AND 保険者（市区町村）別に同じ定義で公表する唯一の公式統計。介護需給を保険者粒度で見る目的に直接対応する |
| 総務省統計局「人口推計」2024年10月1日現在 第11表（政府統計コード 00200524） | 高齢化率という需給の分母側の文脈を都道府県単位で揃えるため。介護保険の基準時点（2025年3月末）とも近い |

## 定義の注意（重要）

- **認定率**は公式値（第1号被保険者に占める第1号認定者の割合、概要第3表）を使用。認定者総数÷第1号被保険者数の計算値（全国20.1%）は「認定者比率（参考）」として分離し、混在させていません。
- **給付費**は介護給付・予防給付の範囲で、高額介護サービス費・高額医療合算介護サービス費・特定入所者介護サービス費を含みません。公表の「給付費総額12兆952億円」とは範囲が異なります。
- **受給者数**の当年度累計は延べ人月です。1ヶ月平均は累計÷12の換算で、サービス間に重複利用があります。

## 検証

47都道府県の合計が公表値と完全一致することを確認済みです（被保険者数 35,839,278人 / 認定者数 7,207,487人 / 給付費 10,618,731,913千円）。詳細はExcel内の「検証ログ」シートを参照。

## 採用しなかったデータ

- **介護保険事業状況報告（月報）**: 速報値で年報とずれるため不採用（月次モニタリング用途では採用候補）。
- **介護サービス施設・事業所調査**: 供給側の統計。本サンプルは需要側+給付に範囲を絞ったため不採用。商品化時は供給レイヤーとして追加し、需給ギャップ分析に拡張する想定です。買い手に価値があるデータは、定義そのまま・注記つきの「参考資料」として有料オプション提供する運用を想定しています。
- **地域包括ケア「見える化」システムの保険者別指標**: 公開範囲・取得形式が安定せず再現性が担保できないため不採用。
- **2020年度以前の認定者数・給付費の exact 系列**: 未取得（全国計Excelの原表レイアウトが異なるため未抽出。被保険者数の10年系列のみ概要第1表から収録）。
